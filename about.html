About Network Intrusion Detection System

Project Overview

Network Intrusion Detection System (NIDS) is designed to monitor network traffic and help detect suspicious activities. This project provides an interface for viewing the dashboard, alerts, and reports.

Project Features

  • Real-Time Monitoring
  • AI-Based Detection
  • Security Alerts
  • Reports & Logs
  • User Management
